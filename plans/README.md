# Kế hoạch dự án

Thư mục này lưu kế hoạch chi tiết của từng Epic trong Product Backlog.

Mỗi file Epic mô tả mục tiêu, phạm vi, quyết định, danh sách công việc,
dependency, tiêu chí hoàn thành, rủi ro và các câu hỏi chưa được chốt.
